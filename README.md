## 🧠 How I Build

- 기능을 먼저 나열하지 않고 **사용자가 완료해야 하는 행동**부터 정의합니다.
- UI 컴포넌트는 **데이터 상태, 권한, 에러, 빈 화면**까지 포함해서 설계합니다.
- 모바일에서 먼저 읽히는지 보고, 데스크톱에서는 정보 구조와 밀도를 정리합니다.
- 배포 후에도 깨지지 않도록 **SEO/OG, 성능, 회귀 QA, 운영 플로우**를 함께 봅니다.
