## 🧠 How I Build

- 화면을 예쁘게 만드는 것보다 **사용자가 목적을 끝까지 완료하는 구조**를 먼저 봅니다.
- 프론트엔드를 중심으로 **API, 데이터 모델, 인증, 배포 흐름**까지 연결합니다.
- 제품이 실제로 운영될 때 필요한 **모바일 사용성, 성능, SEO/OG, 회귀 QA**를 함께 챙깁니다.
- 작은 기능도 “왜 필요한가 → 어디서 막히는가 → 어떻게 반복 사용되는가”를 기준으로 설계합니다.
